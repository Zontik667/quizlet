# 📚 Карточки — модули для заучивания (Python + SQLite)

Простой аналог Quizlet. Модули и карточки хранятся в **базе данных SQLite** (файл `quizcards.db`), поэтому они сохраняются при перезаходе, перезагрузке страницы и даже при смене браузера.

## Что нужно

- **Python 3.8 или новее.** Больше ничего: `pip install` не нужен, SQLite уже встроен в Python.

Проверить, что Python есть:

```
python --version
```

(на macOS/Linux может быть `python3 --version`). Если его нет, скачайте с https://www.python.org/downloads/ (на Windows при установке отметьте галочку **Add Python to PATH**).

## Файлы проекта

Положите все файлы в одну папку:

| Файл | Зачем |
|---|---|
| `server.py` | Сервер и база данных (API) |
| `index.html` | Страница |
| `style.css` | Оформление |
| `app.js` | Вся логика: модули, карточки, заучивание |
| `quizcards.db` | База данных. Создаётся автоматически при первом запуске |

## Запуск

1. Откройте терминал (на Windows: `Win + R` → `cmd`) и перейдите в папку проекта:
   ```
   cd путь/к/папке
   ```
2. Запустите сервер:
   ```
   python server.py
   ```
   (на macOS/Linux: `python3 server.py`)
3. Откройте в браузере: **http://localhost:8000**
4. Остановить сервер: `Ctrl + C` в терминале.

> ⚠️ Файл `index.html` теперь **нельзя открывать двойным кликом**: страница общается с сервером. Всегда заходите через http://localhost:8000.

## Как пользоваться

1. На главной странице нажмите **«+ Новый модуль»**.
2. Введите название и вставьте список слов: одна строка, одна карточка. Разделитель: **Tab** или ` - ` (пробел-тире-пробел).
   ```
   apple	яблоко
   book - книга
   ```
3. Нажмите **«Создать модуль»**. Откроется режим карточек.
4. У каждого модуля три вкладки: **Карточки**, **Заучивание**, **Редактор** (там можно изменить слова или удалить модуль).
5. На главной странице видны все ваши модули. Они всегда на месте.

## Где хранятся данные

В файле `quizcards.db` рядом с `server.py`.

- **Резервная копия:** остановите сервер и скопируйте `quizcards.db`.
- **Перенос на другой компьютер:** скопируйте этот файл вместе с проектом.
- **Сбросить всё:** остановите сервер и удалите `quizcards.db`. Он создастся пустым при следующем запуске.
- **Посмотреть содержимое:** откройте файл в бесплатной программе [DB Browser for SQLite](https://sqlitebrowser.org/).

Структура базы:

```
modules(id, title, created_at, updated_at)
cards(id, module_id → modules.id, position, term, definition)
```

При удалении модуля его карточки удаляются автоматически (`ON DELETE CASCADE`).

## Настройки (необязательно)

Задаются переменными окружения:

| Переменная | По умолчанию | Смысл |
|---|---|---|
| `PORT` | `8000` | Порт сервера |
| `HOST` | `127.0.0.1` | Кто может подключаться. `127.0.0.1` — только этот компьютер |
| `QUIZ_DB` | `quizcards.db` рядом с `server.py` | Путь к файлу базы |

Примеры:

```
# macOS / Linux
PORT=5000 python3 server.py

# Windows (cmd)
set PORT=5000
python server.py
```

### Открыть с телефона (в той же Wi-Fi сети)

1. Запустите с `HOST=0.0.0.0` (macOS/Linux: `HOST=0.0.0.0 python3 server.py`, Windows: `set HOST=0.0.0.0` и затем `python server.py`).
2. Узнайте IP компьютера (Windows: `ipconfig`, macOS/Linux: `ifconfig` или `ip a`), например `192.168.1.25`.
3. На телефоне откройте `http://192.168.1.25:8000`.

⚠️ В приложении **нет входа по паролю**: любой, кто может открыть адрес, видит и меняет все модули. Не открывайте порт в интернет без защиты.

## API (для интересующихся)

| Метод и путь | Действие |
|---|---|
| `GET /api/modules` | Список модулей с количеством карточек |
| `POST /api/modules` | Создать модуль: `{"title": "...", "cards": [{"term": "...", "definition": "..."}]}` |
| `GET /api/modules/<id>` | Модуль со всеми карточками |
| `PUT /api/modules/<id>` | Заменить название и карточки |
| `DELETE /api/modules/<id>` | Удалить модуль |

## Размещение в интернете

Сервер состоит из одного файла и стандартной библиотеки, поэтому его можно запустить на любом VPS командой `python3 server.py` (с `HOST=0.0.0.0`). Но сначала добавьте вход по паролю или закройте доступ через reverse proxy с авторизацией. На бесплатных хостингах с временным диском файл `quizcards.db` может пропадать при перезапуске, нужен постоянный диск (volume).

## Если что-то не работает

- **«Нет связи с сервером. Запущен ли server.py?»** — сервер не запущен или остановлен. Запустите снова.
- **`Address already in use`** — порт занят. Запустите на другом: `PORT=8001 python3 server.py`.
- **`python` не найден** — на macOS/Linux используйте `python3`, на Windows переустановите Python с галочкой **Add Python to PATH**.
